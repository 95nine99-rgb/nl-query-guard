# 프롬프트

프롬프트를 **코드처럼 다룬다.** 파일로 두고 바꿀 때 PR을 올린다.
커밋 로그에 "프롬프트를 왜 바꿨고 정확도가 얼마나 변했는지"가 남아야 한다.

## 규칙

- 파일명: `<용도>.v<N>.txt`
- 바꿀 때 **버전을 올린다.** 덮어쓰지 않는다
- PR 본문에 회귀 테스트 결과(정확도 before/after)를 붙인다
- `PROMPT_VERSION` 테이블의 `git_sha`가 이 디렉터리의 커밋을 가리킨다

## 파일

| 파일 | 용도 | 현재 정확도 |
|---|---|---|
| `intent-classify.v1.txt` | 의도 5종 분류 | 미측정 |
| `sql-where.v1.txt` | WHERE 조건 생성 | 미측정 |
